# Honeypot Tools

This directory contains various tools for working with the honeypot system.

## Available Tools

### 1. Honeypot Activity Simulator

Located in the `simulator` directory, this tool simulates various types of attacks on the honeypot system for testing purposes.

[Learn more about the Simulator](simulator/README.md)

### 2. Honeypot Configuration Generator

Located in the `generator` directory, this tool generates configuration files for different honeypot services.

[Learn more about the Generator](generator/README.md)

### 3. Honeypot Log Analyzer

Located in the `analyzer` directory, this tool analyzes honeypot logs to extract useful information and generate reports.

[Learn more about the Analyzer](analyzer/README.md)

## Usage

Each tool has its own README file with detailed usage instructions. Navigate to the tool's directory to learn more.

## Requirements

- Python 3.6+
- Additional requirements are listed in each tool's README file
